# 우선업무 변경 이력과 되찾기

우선업무 하단 또는 설정의 ‘변경 이력 · 되찾기’에서 확인합니다.

- 기능 적용 후 저장한 우선업무의 수정 전 내용, 완료 상태 변경, 삭제를 기록합니다.
- 최근 200건을 계정의 기존 DB 상태에 함께 저장합니다. 과거 날짜의 원본 변경도 날짜별로 확인할 수 있습니다.
- 이력이 생기기 전에 사라진 내용을 재구성하는 기능은 아닙니다. 시간별 일정·주간 업무·메모의 이력은 대상에 포함하지 않습니다.
- 복원은 두 단계 확인 후 오늘에 독립적인 미완료 업무를 추가합니다. 현재 업무를 덮어쓰거나 계정 전체를 과거로 되돌리지 않습니다.
- Money·반복 원장 연결과 시간별 일정은 복원하지 않습니다. 복원한 업무의 문구를 직접 수정하면 일반 업무처럼 시간 연결 로직이 다시 적용됩니다.
- 같은 이력으로 중복 복원하지 않도록 복원본 ID를 고정합니다. 기존 CAS 저장과 항목별 병합 경로를 사용합니다.
- 복원 직후에는 앱의 저장 상태로 DB 저장 완료를 확인합니다.

검증: `node tests/task_recovery_regression.js`, `tests/browser/task-recovery.spec.js`.
