# Beyond Work 특징 및 사용설명서

## 1. Beyond Work 개요

Beyond Work는 하루의 우선업무, 시간별 일정, 주간 초점, 프로젝트, Money 흐름, 메모, AI 코칭을 하나의 실행 시스템으로 연결한 웹 기반 플래너입니다.

일반 할 일 앱처럼 단순히 목록을 쌓는 방식이 아니라, 오늘 해야 할 일과 실제 시간표를 연결하고, 완료 여부와 이월 상태를 다음 계획에 반영하며, 사용자의 목표와 패턴을 바탕으로 AI 코칭을 제공하는 것을 목표로 합니다.

### 핵심 방향

- 오늘 해야 할 일을 먼저 정리합니다.
- 중요한 업무를 실제 시간표에 배치합니다.
- 완료, 진행중, 취소, 연기, 위임 상태를 기록합니다.
- 미완료 업무는 정해진 규칙에 따라 다음 날 또는 지정일로 이어집니다.
- 주간, 월간, 프로젝트, Money 데이터를 오늘의 실행과 연결합니다.
- 사용자가 입력한 목표, 역할, 건강, 업무 패턴을 기반으로 AI 코칭을 제공합니다.
- 모바일, 아이패드, 맥, PC에서 같은 계정으로 접속해 같은 데이터를 봅니다.

## 2. 주요 특징

### 2.1 Today 중심 구조

앱의 중심은 `Today` 섹션입니다. 오늘 해야 할 우선업무와 시간별 일정이 동시에 보이도록 구성되어 있습니다.

Today 섹션은 다음 네 영역으로 구성됩니다.

- Weekly: 이번 주 주요 일정과 역할별 핵심 행동
- Top Tasks: 오늘의 우선업무
- Schedule: 시간별 일정
- Memo: 오늘의 메모와 일일 기록

클래식 모드에서는 Weekly, Top Tasks, Schedule, Memo를 한 화면에 배치하는 것을 목표로 합니다. CEO 모드와 모바일 화면에서는 Top Tasks와 Schedule을 우선 보여주고, Weekly와 Memo는 좌우 이동 또는 버튼으로 접근합니다.

### 2.2 우선업무와 시간표 연결

우선업무에 `10:00`, `오후 2:00`, `19:00`처럼 시간이 포함되면 해당 시간대의 시간별 일정에 자동 반영됩니다.

예:

- 우선업무: `분양팀 회의 11:30`
- 시간별 일정: `11:30` 칸에 같은 내용 자동 표시

완료된 업무는 시간표에 유지됩니다. 취소, 연기, 위임처럼 실제 그 시간대에 실행되지 않는 상태가 되면 시간별 일정에서 제거됩니다.

### 2.3 상태 기반 업무 관리

우선업무는 단순 체크가 아니라 실행 상태를 기록합니다.

- 완료: 업무를 끝낸 상태
- 진행중: 아직 처리 중인 상태
- 취소: 더 이상 진행하지 않는 상태
- 연기: 특정 날짜 또는 미정으로 넘기는 상태
- 위임: 다른 사람에게 맡긴 상태

상태에 따라 업무 글자에는 붉은 중앙선이 표시됩니다. 단, 글자색은 검정 계열을 유지해 가독성을 해치지 않습니다.

### 2.4 반복 우선업무

매일, 매주, 매월, 매년 반복되는 업무를 만들 수 있습니다.

반복 업무는 다음 기준으로 작동합니다.

- 매일 반복: 선택한 요일에 생성
- 매주 반복: 주차와 요일을 기준으로 생성
- 매월 반복: 선택한 날짜에 생성
- 매년 반복: 기념일 또는 연간 일정과 연결

반복업무마다 이월 여부를 설정할 수 있습니다.

- 이월 켜짐: 완료되지 않으면 다음 반복 주기 전날까지 이어짐
- 이월 꺼짐: 해당 날짜에만 표시

### 2.5 시간별 일정 병합

시간별 일정은 30분 또는 1시간 단위로 사용할 수 있습니다.

시간표 입력칸을 선택하면 병합 옵션을 사용할 수 있습니다.

- 종일
- 오전
- 오후
- 인접 시간 병합
- 병합 해제
- 되돌리기

병합한 일정은 시작시간과 종료시간을 기준으로 하나의 일정 블록처럼 표시됩니다. 병합된 일정의 문구는 중앙 정렬을 기본으로 하며, 칸이 부족할 때만 자연스럽게 줄바꿈됩니다.

### 2.6 Weekly Focus

Weekly 섹션은 한 주의 방향을 잡는 공간입니다.

구성:

- 금주의 주요 일정
- 개인
- 가족
- 성장
- 공헌
- 기타 역할별 목표와 핵심 행동

금주의 주요 일정은 체크되지 않은 항목만 다음 주로 이어집니다. 체크된 항목은 이월되지 않습니다.

### 2.7 Month, Year, Calendar

월간과 연간 섹션에서는 날짜 기반 계획을 볼 수 있습니다.

달력 원칙:

- 모든 달력은 일요일부터 시작
- 날짜 표기는 연도, 월, 일, 요일 순서
- 요일은 한자 표기를 기본 사용
- 공휴일, 국경일, 주요 명절 표시
- 음력은 매월 1일, 10일, 20일, 30일 단위로 표시

월간 달력에서 특정 날짜를 더블클릭하면 해당 날짜의 Today 섹션으로 이동합니다.

### 2.8 Money

Money 섹션은 매달 반복되는 지출, 수입, 카드대금, 이자, 할부금, 관리비, 중요한 현금흐름 이슈를 관리합니다.

주요 기능:

- 월별 Money Check
- 반복 지출 관리
- 수입, 지출 구분
- 금액 천 단위 쉼표 표시
- 예정, 확인, 보류, 완료 상태 관리
- 종료 없음 또는 종료일 설정
- 해당 날짜에 도래한 Money 항목을 오늘의 우선업무에 반영
- Money 태그로 업무와 연결

반복 지출은 입력일을 시작일로 보고, 실제 반복일이 도래하는 날부터 우선업무에 표시됩니다. 현재 날짜 기준 한 달 이내의 항목만 우선업무에 올려 과도한 업무 생성이 일어나지 않도록 합니다.

### 2.9 Projects

Projects 섹션은 장기 업무와 실행 항목을 관리합니다.

구성:

- 프로젝트 목록
- 프로젝트 상세 페이지
- 목표, 상태, 다음 행동
- 프로젝트별 메모
- 프로젝트별 Money 시뮬레이션

프로젝트 목록에서 항목을 선택하면 상세 페이지가 열립니다. 다시 목록으로 돌아갈 수 있도록 닫기 또는 좌우 이동 구조를 지원합니다.

### 2.10 Memo

Memo 섹션은 Today 섹션의 메모를 날짜별로 모아 보는 기록 저장소입니다.

주요 기능:

- 날짜별 메모 자동 정리
- 제목 또는 첫 줄 자동 제목
- 메모 검색
- 오늘 섹션에서 해당 날짜 메모 열기
- 일일 회고와 메모 통합 관리

아이폰 메모 앱처럼 빠르게 적고, 이후 날짜별로 다시 찾는 구조를 목표로 합니다.

### 2.11 AI Coaching

AI 코칭은 Beyond Work의 차별화 기능입니다.

코칭 아이콘은 전체 앱 또는 각 섹션에서 사용할 수 있습니다.

역할:

- 전체 코칭: 오늘의 방향, 놓친 부분, 실행 흐름 제안
- 우선업무 코칭: 업무 리스트 추천, 우선순위 조정
- 시간별 일정 코칭: 일정 배치와 시간 블록 제안
- Weekly 코칭: 주간 초점과 역할 균형 점검
- Money 코칭: 지출 일정, 현금흐름 리스크, 확인 업무 제안
- Projects 코칭: 다음 행동, 병목, 일정 분해 제안
- Memo 코칭: 기록 요약, 회고 포인트 제안

AI 코칭은 사용자가 설정에 입력한 정체성, 목표, 역할, 건강, 업무 패턴, 현재 일정과 기록을 참고합니다.

### 2.12 날씨 기반 코칭

Today 섹션에는 오늘 날씨가 표시됩니다.

오늘 날짜에서는 날짜 오른쪽에 날씨 아이콘과 최저, 최고 온도를 표시합니다. 날씨 정보는 AI 코칭의 문맥에도 사용될 수 있습니다.

예:

- 비 오는 날: 외부 일정 점검, 이동시간 확보 제안
- 더운 날: 체력 소모가 큰 업무를 오전에 배치 제안
- 맑은 날: 현장 방문 또는 외부 일정 실행 제안

### 2.13 보안 모드

일정 시간 사용하지 않으면 개인적인 내용이 가려지는 보안 모드를 사용할 수 있습니다.

주요 기능:

- 일정 시간 후 내용 블라인드 처리
- Beyond Work 타이틀만 표시
- 비밀번호 또는 생체인증 방식 고려
- PC 화면에서 개인 일정 노출 방지

### 2.14 승인 기반 사용자 관리

신규 사용자는 관리자의 승인 과정을 거쳐 사용할 수 있도록 설계되어 있습니다.

관리자 계정에서는 다음을 확인할 수 있습니다.

- 누적 가입자
- 승인 대기자
- 승인된 사용자
- 보류 또는 정지 사용자
- 사용자 등급 조정

등급:

- CEO
- Director
- Manager
- Staff

관리자 기능은 지정된 관리자 계정에서만 보입니다.

## 3. 기본 사용 흐름

### 3.1 처음 접속

1. 로그인 페이지에서 이메일과 비밀번호를 입력합니다.
2. 승인된 계정이면 대시보드로 이동합니다.
3. 앱은 마지막 데이터 또는 서버 데이터를 불러옵니다.
4. 오늘 날짜의 Today 화면이 기본으로 열립니다.

### 3.2 매일 아침 사용 순서

1. Today 화면을 엽니다.
2. Weekly를 확인해 이번 주 초점을 봅니다.
3. 오늘의 우선업무를 입력합니다.
4. 시간이 있는 업무는 시간까지 함께 적습니다.
5. 시간별 일정에 업무가 자동 배치되는지 확인합니다.
6. 비어 있는 시간에 중요한 업무를 추가 배치합니다.
7. AI 코칭을 눌러 오늘의 실행 제안을 확인합니다.

### 3.3 업무 중 사용 순서

1. 업무가 끝나면 체크합니다.
2. 진행 중이면 진행 상태로 표시합니다.
3. 취소, 연기, 위임은 중요도 메뉴 또는 상태 메뉴에서 처리합니다.
4. 연기 업무는 날짜를 지정하거나 미정으로 둡니다.
5. 일정 변경이 있으면 시간표에서 병합, 해제, 되돌리기를 사용합니다.

### 3.4 하루 마감 사용 순서

1. 완료된 업무 수를 확인합니다.
2. 완료하지 못한 업무를 연기, 취소, 위임 또는 이월 상태로 정리합니다.
3. Memo에 오늘의 결정, 배운 점, 후속 조치를 적습니다.
4. 필요하면 AI 코칭으로 오늘의 실행 흐름을 점검합니다.

## 4. Today 섹션 사용법

### 4.1 날짜 이동

날짜 행에서 다음 기능을 사용할 수 있습니다.

- 왼쪽 화살표: 하루 전
- 오른쪽 화살표: 하루 후
- 오늘 버튼: 오늘 날짜로 이동
- 날짜 클릭: 달력 팝업 열기

달력에서 날짜를 선택하면 해당 날짜의 Today 섹션으로 이동합니다.

### 4.2 Weekly, Memo 이동

날짜 아래의 흐르는 배너 양쪽에 Weekly와 Memo 이동 버튼이 있습니다.

- Weekly: 왼쪽 주간 초점 페이지
- Memo: 오른쪽 메모 페이지

모바일에서는 좌우 이동이 지원되며, 안정성을 위해 버튼 이동도 함께 제공합니다.

### 4.3 우선업무 입력

우선업무 행에 내용을 입력합니다.

권장 입력 방식:

- 업무명만 입력: `계약서 검토`
- 시간 포함 입력: `계약서 검토 10:00`
- 장소 포함 입력: `현장 방문 14:00`
- Money 관련 입력: `카드대금 확인`

시간이 포함된 경우 시간별 일정에 자동 배치됩니다.

### 4.4 중요도 선택

중요도는 업무 성격을 빠르게 구분하기 위한 표시입니다.

- A: 가장 중요한 업무
- B: 중요하지만 A보다 낮은 업무
- C: 처리하면 좋은 업무
- ?: 아직 중요도를 정하지 않은 업무
- 취소
- 연기
- 위임

중요도 선택은 업무의 위치를 갑자기 바꾸지 않도록 입력 순서를 최대한 유지하는 방향으로 설계합니다.

### 4.5 체크박스 상태

체크박스는 실행 상태를 빠르게 표현합니다.

- 빈칸: 미완료
- V: 완료
- 점: 진행중

위임과 연기는 중요도 메뉴에서 선택합니다. 체크박스에 너무 많은 상태를 넣으면 사용성이 떨어지므로, 실행 체크와 상태 변경을 분리합니다.

### 4.6 삭제

우선업무 삭제 버튼은 주로 확대 화면에서 표시됩니다. 실수 삭제 방지를 위해 확인 과정을 둡니다.

삭제 기준:

- 일반 업무 삭제: 해당 날짜의 업무 삭제
- 이월 업무 삭제: 삭제 당일 및 이후 표시 중단
- 반복 업무 삭제: 이후 반복 생성 중단, 과거 기록 유지

### 4.7 확대 모드

모바일에서는 우선업무와 시간별 일정이 작은 화면에 나란히 보입니다. 더 편하게 입력하려면 확대 버튼을 사용합니다.

- 돋보기 +: 확대
- 돋보기 -: 축소

확대 화면에서는 글자 크기와 터치 영역이 커지고, 삭제와 병합 같은 세부 조작 버튼이 더 명확하게 표시됩니다.

## 5. 시간별 일정 사용법

### 5.1 기본 입력

시간별 일정의 입력칸을 선택하고 내용을 입력합니다.

기본 단위:

- 30분 단위
- 1시간 단위

단위는 설정에서 변경할 수 있습니다. 변경된 시간 단위는 변경한 날짜부터 적용하고, 과거 날짜는 당시 설정을 유지하는 방향으로 관리합니다.

### 5.2 병합

긴 일정은 여러 시간대를 병합해 하나의 일정처럼 표시합니다.

예:

- 10:00부터 12:00까지 회의
- 13:00부터 15:00까지 현장 점검

병합된 일정은 하나의 넓은 블록으로 표시됩니다.

### 5.3 병합 해제

병합된 일정의 `-` 버튼을 눌러 병합을 해제합니다.

병합 해제 후에는 원래 시간 단위로 나뉘며, 필요한 경우 일정 내용을 다시 조정합니다.

### 5.4 되돌리기

실수로 병합하거나 삭제한 경우 되돌리기를 사용할 수 있습니다.

되돌리기는 특히 다음 상황에서 유용합니다.

- 종일 병합을 실수로 누른 경우
- 오전, 오후 병합을 잘못 적용한 경우
- 긴 일정 병합을 해제했다가 다시 되돌리고 싶은 경우

### 5.5 현재 시간 표시

오늘 날짜의 시간표에서는 현재 시간대가 붉은색 시간 표시로 구분됩니다.

현재 시간은 별도 위치로 떠다니지 않고, 원래 시간 위치에서 색상만 바뀌도록 설계합니다. 이렇게 해야 시간표가 흔들리거나 겹치지 않습니다.

## 6. Weekly 사용법

### 6.1 주간 이동

주간 섹션에서는 시작일과 종료일이 표시됩니다.

- 주간 시작: 일요일
- 주간 종료: 토요일

주간 제목을 클릭하면 달력으로 다른 주를 선택할 수 있습니다.

### 6.2 금주의 주요 일정

금주의 주요 일정에는 이번 주에 꼭 처리해야 할 항목을 적습니다.

항목 기능:

- 체크
- 진행중
- 취소
- 연기
- 위임
- 중요도 선택
- 삭제

체크되지 않은 항목은 다음 주로 이어질 수 있습니다. 체크된 항목은 이월되지 않습니다.

### 6.3 역할별 핵심 행동

개인, 가족, 성장, 공헌 등 역할별로 이번 주 목표와 행동을 적습니다.

권장 방식:

- 목표는 한 문장으로 짧게 적습니다.
- 핵심 행동은 1개 또는 2개만 적습니다.
- 너무 많은 항목을 넣기보다 실제 실행 가능한 항목만 적습니다.

### 7.1 월간 보기

월간 섹션에서는 한 달의 흐름을 봅니다.

가능한 작업:

연간 섹션은 1년 전체의 일정과 큰 흐름을 보는 용도입니다.

권장 사용:

Money 섹션은 월별로 관리합니다.

월 이동:

- 좌우 스와이프

## 12. Settings 사용법

설정은 크게 사용자 설정과 앱 설정으로 나뉩니다.

## 13. 데이터 저장 원칙

Beyond Work는 웹 앱입니다. 같은 계정으로 로그인하면 어떤 기기에서도 같은 데이터를 보는 것을 목표로 합니다.

중요 원칙:

- 서버 DB가 기준입니다.
- 로컬 기기별 별도 데이터에 의존하지 않습니다.
- 페이지를 열면 DB에서 데이터를 읽어와 표시합니다.
- 입력한 내용은 DB에 저장되어야 합니다.
- 백업은 보조 안전장치입니다.

따라서 "동기화"라는 개념보다 "웹에 저장된 같은 데이터를 본다"는 구조로 이해하는 것이 정확합니다.

## 14. 백업과 복원

설정에서 데이터를 파일로 내보내고 가져올 수 있습니다.

권장 방향:

- Excel 파일로 내보내기
- Excel 파일로 가져오기
- 정기 백업은 메일 발송 방식 검토
- DB 데이터가 기준이고, 백업 파일은 복구용 보조 수단

백업 파일에는 개인 일정, Money 정보, 메모가 포함될 수 있으므로 안전하게 보관해야 합니다.

차별 요소:

- 반복업무와 이월 규칙
- Money 이벤트의 우선업무 반영

- 데이터는 DB 중심으로 저장

단순 플래너가 아니라 "실행 관리 시스템"에 가깝습니다.

## 18. 자주 묻는 질문

### Q. 같은 계정으로 아이폰과 아이패드에서 같은 내용이 보이나요?

네. 같은 계정으로 로그인하면 DB에 저장된 같은 데이터를 보는 구조입니다.

### Q. 우선업무에 시간을 적으면 시간표에 자동으로 들어가나요?

네. `10:00`, `14:30`, `오후 2:00`처럼 시간을 포함하면 해당 시간대에 반영됩니다.

### Q. 연기한 업무는 어떻게 보이나요?

연기 날짜를 지정하면 해당 날짜의 우선업무에 표시됩니다. 날짜를 지정하지 않으면 미정으로 표시됩니다.

### Q. 완료한 업무도 시간표에서 사라지나요?

아니요. 완료는 실제 수행한 기록이므로 시간표에 유지합니다. 취소, 연기, 위임처럼 실제 실행되지 않는 상태만 시간표에서 제거합니다.

### Q. 반복 지출이 오늘 우선업무에 너무 많이 올라오면 어떻게 하나요?

반복일이 오늘이 아닌 항목은 올라오지 않는 것이 정상입니다. 반복일, 시작일, 종료 조건을 확인합니다.

### Q. AI 코칭은 어떤 정보를 참고하나요?

오늘의 우선업무, 시간별 일정, Weekly, Projects, Money, Memo, 사용자 설정, 날씨 정보를 참고합니다.

### Q. 보안 모드는 무엇인가요?

일정 시간 사용하지 않을 때 플래너 내용을 가려 개인 일정이 노출되지 않게 하는 기능입니다.

## 19. 관리자 사용법

관리자 계정에서는 사용자 승인 관리가 보입니다.

관리자 절차:

1. 신규 가입자 확인
2. 이메일과 등급 확인
3. 승인, 보류, 정지 결정
4. 필요하면 등급 조정
5. 승인된 사용자만 앱 데이터 화면 접근

관리자 기능은 일반 사용자에게 표시되지 않아야 합니다.

## 20. 운영 원칙

Beyond Work를 안정적으로 운영하기 위한 기준입니다.

- DB를 데이터 기준으로 둡니다.
- 로컬 저장 데이터로 운영 판단을 하지 않습니다.
- 삭제 기능에는 확인 절차를 둡니다.
- 반복 업무와 반복 지출은 과거 기록을 훼손하지 않습니다.
- 변경은 변경일 이후에만 반영하는 것을 원칙으로 합니다.
- 모바일, 아이패드, 데스크톱 화면을 모두 확인한 후 배포합니다.
- 유료 출시 수준의 완성도를 기준으로 UI와 기능을 검수합니다.
