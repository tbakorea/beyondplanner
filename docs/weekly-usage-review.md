# 월요일 플래너 사용 리뷰

매주 월요일 오전 9시(한국 시간)에 이전 월요일부터 일요일까지 검토하고, 사용 중 불편했던 지점과 다음 개발 제안을 현재 Codex 대화에 남깁니다.

- 지난주 사용 제보와 재현 결과를 확인합니다. Git 변경 이력은 제보와 수정 상태를 연결하는 데 사용합니다.
- 플래너 백업이 있으면 아래 명령으로 계정의 저장 기록을 집계합니다. 설정의 내보내기로 받은 `beyond-work-excel-날짜.xls`를 Mac의 다운로드 폴더에 두거나, 직접 제공한 백업 파일을 사용합니다.
- 제안은 최대 세 가지입니다. 각 제안에 관찰한 근거, 불편이 생긴 화면이나 동작, 바꿀 내용, 확인 방법을 적습니다.

```sh
python3 scripts/weekly_usage_summary.py "/경로/beyond-work-excel-2026-11-16.xls"
```

백업에서 날짜별 업무·일정·메모 기록과 시각이 남은 우선업무 변경 이력을 집계합니다. 예약된 일정과 반복 자동 생성이 날짜별 기록에 들어갈 수 있습니다. 우선업무 이력은 최근 최대 200건으로, 추가·화면 방문·클릭은 이 이력에서 집계할 수 없습니다. 내보낸 시점과 이력 제한을 확인한 뒤 사용 제보와 함께 해석합니다.

백업의 업무 제목, 메모 내용, 계정 정보는 집계 결과에 포함하지 않습니다. 백업 파일은 저장소 밖에 보관합니다.
